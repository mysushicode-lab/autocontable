🔄 COMPLETE FLOWS
─────────────────

Admin Invites PME:
  Portfolio → Dossier → "Accès"
  ↓
  PermissionsModal: Email + Permission Level
  ↓
  Backend: Generate InvitationToken → Return join_url
  ↓
  Admin: Copy + Send to PME

PME Signs Up (Option A - Manual):
  Click link → /join page
  ↓
  Fill form: name, username, password
  ↓
  Backend: Validate token → Create User (CLIENT) → Grant Permission
  ↓
  Redirect → /portal (Mon Espace)

PME Signs Up (Option B - Google OAuth):
  Click "Google" → Google OAuth → Authenticate
  ↓
  Backend: Validate token → Create User via OAuth → Grant Permission
  ↓
  Redirect → /portal

PME Signs Up (Option C - LinkedIn OAuth):
  Same as Google (different provider)
